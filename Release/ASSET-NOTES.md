# Project SinFall tester assets

Preserved game cache, divided into numbered ZIP packs for the Android installer.
The main tester's `release.json` pins every filename, size and SHA-256 checksum.

Install the Hub from the [main tester release](https://github.com/CloudyCodez/Project-SinFall/releases/tag/v0.1.0-tester.1).
The game setup downloads these packs, verifies them, and installs them into its own app storage.
No manual extraction or PC transfer is needed.

This release contains asset data only. The main tester release contains the Hub, client download parts and setup manifest.
